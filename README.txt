CINEWORLD MOVIE WEBSITE

1. Open the Movie-Website folder in VS Code.
2. Install the Live Server extension.
3. Right-click the root index.html file.
4. Select Open with Live Server.

Folder guide:
- index.html: main home page
- HTML: all additional pages
- CSS: separate CSS file for each page plus common.css
- JS: movie data and page functionality

Note: Movie poster images are loaded from TMDB image URLs, so an internet connection is needed.
This is a front-end sample project and does not use a backend or database.
