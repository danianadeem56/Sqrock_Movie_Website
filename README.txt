🎬 SQROCK MOVIE WEBSITE

🌟 About The Project

The Sqrock Movie Website is a modern, attractive, and fully responsive website developed as part of the Sqrock IT Solutions – Frontend Development Internship (Project Phase 1).

This website is designed to provide users with a simple and enjoyable experience for exploring different movies. Users can browse trending movies, search for their favorite movies, explore different movie genres, and view important movie information such as ratings, release years, and descriptions.

The main purpose of this project is to improve frontend development skills and gain practical experience in creating responsive and user-friendly websites.

✨ Features

Attractive Home Page with a modern hero section.

Responsive Navigation Bar.

Trending and Popular Movies Section.

Movie Cards with Posters and Details.

Movie Ratings and Release Years.

Search Functionality to find movies by name.

Different Movie Categories and Genres.

Smooth Hover Effects and Animations.

Fully Responsive and Mobile-Friendly Design.

Clean and User-Friendly Interface.
